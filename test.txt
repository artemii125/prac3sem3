
Создать покупатель-продавец
curl -X POST -H "Content-Type: application/json" -d '{"username":"user1"}' http://127.0.0.1:8080/user
curl -X POST -H "Content-Type: application/json" -d '{"username":"user2"}' http://127.0.0.1:8080/user

Баланс
curl -H "X-USER-KEY: 210bc6f99d6ace015004a513767fd028" http://127.0.0.1:8080/balance
curl -H "X-USER-KEY: 03af9d0d2695ad1fe4ebf96f1e968a59" http://127.0.0.1:8080/balance

Ордер на покупку 300 RUB за USDT по цене 0.015
curl -X POST -H "Content-Type: application/json" -H "X-USER-KEY: 210bc6f99d6ace015004a513767fd028" -d '{"pair_id":2,"quantity":300,"price":0.015,"type":"buy"}' http://127.0.0.1:8080/order

Баланс (RUB=1000, USDT=995.5)
curl -H "X-USER-KEY: 210bc6f99d6ace015004a513767fd028" http://127.0.0.1:8080/balance

Просмотр активных ордеров
curl http://127.0.0.1:8080/order

Ордер на продажу 200 RUB за USDT по цене 0.01
curl -X POST -H "Content-Type: application/json" -H "X-USER-KEY: 03af9d0d2695ad1fe4ebf96f1e968a59" -d '{"pair_id":2,"quantity":200,"price":0.01,"type":"sell"}' http://127.0.0.1:8080/order

Проверка балансов после матчинга (RUB=1200, USDT=996.5), (RUB=800, USDT=1002)
curl -H "X-USER-KEY: 210bc6f99d6ace015004a513767fd028" http://127.0.0.1:8080/balance
curl -H "X-USER-KEY: 03af9d0d2695ad1fe4ebf96f1e968a59" http://127.0.0.1:8080/balance

Проверка пар и лотов
curl http://127.0.0.1:8080/pair
curl http://127.0.0.1:8080/lot

Удаление оставшегося ордера покупателя
curl -X DELETE -H "Content-Type: application/json" -H "X-USER-KEY: 210bc6f99d6ace015004a513767fd028" -d '{"order_id":1}' http://127.0.0.1:8080/order

Проверка баланса покупателя (100*0.015=1.5 USDT = 998)
curl -H "X-USER-KEY: 210bc6f99d6ace015004a513767fd028" http://127.0.0.1:8080/balance

ИТОГ
покупатель: 1200 RUB, 998 USDT (купил 200 RUB за 2 USDT)
продавец: 800 RUB, 1002 USDT (продал 200 RUB за 2 USDT)

ДОПОЛНИТЕЛЬНЫЕ ЭНДПОИНТЫ:
==========================
GET  /lot      - список всех лотов (валют)
GET  /pair     - список всех торговых пар
GET  /order    - список всех ордеров
GET  /balance  - баланс пользователя (требует X-USER-KEY)
POST /user     - создание нового пользователя
POST /order    - создание нового ордера (требует X-USER-KEY)
DELETE /order  - удаление ордера (требует X-USER-KEY)

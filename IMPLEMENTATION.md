## Архитектура

### Компоненты
1. **DBrun** - сервер базы данных (порт 7432)
   - Обработка SQL-подобных запросов
   - Хранение данных в файлах CSV
   - TCP сервер для сетевых подключений

2. **ExchangeServer** - HTTP сервер биржи (порт 8080)
   - HTTP парсер запросов
   - Маршрутизация API endpoints
   - Бизнес-логика биржи
   - Клиент для подключения к БД

### Классы
- `Exchange` - основная логика биржи
  - Инициализация лотов и пар
  - Создание пользователей и ордеров
  - Сопоставление ордеров (matching engine)
  - Управление балансами

- `HttpServer` - HTTP сервер
  - Парсинг HTTP запросов
  - Обработка методов (GET, POST, DELETE)
  - Формирование JSON ответов

## Особенности реализации

### Matching Engine
При создании нового ордера:
1. Ищутся встречные ордера (buy ↔ sell)
2. Проверяется совпадение цен
3. Выполняются сделки по цене продавца
4. Обновляются балансы обоих участников
5. Ордера закрываются или обновляются

### Управление балансами
- При создании buy-ордера блокируется валюта покупки
- При создании sell-ордера блокируется продаваемый актив
- При отмене ордера средства возвращаются
- При исполнении сделки балансы обновляются атомарно

### Безопасность
- Проверка ключа пользователя для всех операций
- Проверка достаточности средств перед созданием ордера
- Проверка владельца при удалении ордера

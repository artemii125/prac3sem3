СЦЕНАРИЙ ТЕСТИРОВАНИЯ КРИПТОБИРЖИ
====================================

1. Запуск серверов (в разных терминалах):
   ./start_db.sh
   ./start_exchange.sh

2. Создание двух пользователей:
   curl -X POST -H "Content-Type: application/json" -d '{"username":"user1"}' http://127.0.0.1:8080/user

   curl -X POST -H "Content-Type: application/json" -d '{"username":"user2"}' http://127.0.0.1:8080/user

3. Проверка начальных балансов (должно быть по 1000 каждой валюты):
   curl -H "X-USER-KEY: 7503b6f0b9e80853e98e4c1bdbc34c6e" http://127.0.0.1:8080/balance
   curl -H "X-USER-KEY: b22dfa2cb348129faa7b36492b449a6d" http://127.0.0.1:8080/balance

4. User1 создает ордер на покупку 300 RUB за USD по цене 0.015:
   curl -X POST -H "Content-Type: application/json" -H "X-USER-KEY: 7503b6f0b9e80853e98e4c1bdbc34c6e" -d '{"pair_id":1,"quantity":300,"price":0.015,"type":"buy"}' http://127.0.0.1:8080/order

5. Проверка баланса user1 (должно списаться 300*0.015=4.5 USD):
   curl -H "X-USER-KEY: 7503b6f0b9e80853e98e4c1bdbc34c6e" http://127.0.0.1:8080/balance
   # Ожидается: RUB=1000, USD=995.5

6. Просмотр активных ордеров:
   curl http://127.0.0.1:8080/order
   # Должен быть 1 ордер: order_id=1, quantity=300, price=0.015, type=buy

7. User2 создает ордер на продажу 200 RUB за USD по цене 0.01:
   curl -X POST -H "Content-Type: application/json" -H "X-USER-KEY: b22dfa2cb348129faa7b36492b449a6d" -d '{"pair_id":1,"quantity":200,"price":0.01,"type":"sell"}' http://127.0.0.1:8080/order

8. Проверка балансов после матчинга:
   curl -H "X-USER-KEY: 7503b6f0b9e80853e98e4c1bdbc34c6e" http://127.0.0.1:8080/balance
   # Ожидается: RUB=1200 (+200), USD=997 (списано 4.5, вернулось 1, потрачено 2)

   curl -H "X-USER-KEY: b22dfa2cb348129faa7b36492b449a6d" http://127.0.0.1:8080/balance
   # Ожидается: RUB=800 (-200), USD=1002 (+2)

9. Просмотр ордеров (должен остаться частично исполненный ордер user1):
   curl http://127.0.0.1:8080/order
   # Ожидается: order_id=1, quantity=100, price=0.015, type=buy, closed=''
   # order_id=2 должен быть закрыт (closed=timestamp)

10. Проверка пар и лотов:
    curl http://127.0.0.1:8080/pair
    curl http://127.0.0.1:8080/lot

11. Удаление оставшегося ордера user1:
    curl -X DELETE -H "Content-Type: application/json" -H "X-USER-KEY: 7503b6f0b9e80853e98e4c1bdbc34c6e" -d '{"order_id":1}' http://127.0.0.1:8080/order

12. Проверка баланса user1 (должны вернуться 100*0.015=1.5 USD):
    curl -H "X-USER-KEY: 7503b6f0b9e80853e98e4c1bdbc34c6e" http://127.0.0.1:8080/balance
    # Ожидается: RUB=1200, USD=998.5 (997 + 1.5)

ИТОГОВЫЕ БАЛАНСЫ:
==================
User1: 1200 RUB, 998 USD (купил 200 RUB за 2 USD)
User2: 800 RUB, 1002 USD (продал 200 RUB за 2 USD)

ДОПОЛНИТЕЛЬНЫЕ ЭНДПОИНТЫ:
==========================
GET  /lot      - список всех лотов (валют)
GET  /pair     - список всех торговых пар
GET  /order    - список всех ордеров
GET  /balance  - баланс пользователя (требует X-USER-KEY)
POST /user     - создание нового пользователя
POST /order    - создание нового ордера (требует X-USER-KEY)
DELETE /order  - удаление ордера (требует X-USER-KEY)
